# The Stardew Valley Checklist
A simple web checklist for 100% [Stardew Valley](https://store.steampowered.com/app/413150/Stardew_Valley/) completion.
## Features:
- Cooking, crafting, and fishing checklists
- Completed entries automatically move to the bottom
- Offline, localStorage saving
## Stats:
- 81 cooking recipes
- 145 crafting recipes
- 77 fish
